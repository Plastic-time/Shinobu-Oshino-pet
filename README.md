# 忍野忍 · Shinobu Oshino Pet

《化物语》头盔与护目镜造型的忍野忍宠物。提供 **GPT 宠物版**和**独立 Windows 桌宠版**。

An unofficial Shinobu Oshino companion for ChatGPT Pets and Windows desktop.

## GPT 宠物版

双膝收起，双手自然垂在腿间。重新整理了大腿、手臂与裙摆的遮挡关系，保留坐姿的空间阴影，并加强腿部轮廓。

待机和点击时轻微眨眼。双脚保持静止，未启用晃脚、跑动、跳跃和鼠标转头。

![动作预览](previews/four-states.png)

Pets 的帧数、播放节奏、显示大小和位置由客户端控制。预览使用对应帧时长。

## 独立桌宠版

![Windows 独立桌宠](previews/desktop-preview.png)

Windows 版仍为 v2.1.0 的安静抱膝造型。解压后双击 `Shinobu-Oshino-pet.exe` 即可运行。单击或双击眨眼，按住左键拖动，右键打开设置或退出。

支持四档大小、暂停动画和托盘菜单。离线运行，无需账号。适用于 Windows 10 / 11；已在 Windows 11 验证。

## 素材与布局

GPT 精灵图为 1536 × 2288 px，每格 192 × 208 px，保留 Pets v2 的 8 列 × 11 行、73 个有效格布局。实际内容为眨眼及静止坐姿；兼容状态名不代表启用了对应动作。
